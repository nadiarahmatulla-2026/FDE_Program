## THE FLOW (5 STEPS)

```
1. PREPARE
   └─ Copy: Scenario-5-Comprehensive-Spec-GFM.md (full text)
   └─ Copy: Prompt from CLOSED-BUILD-LOOP-INSTRUCTIONS.md

2. HAND TO CLAUDE
   └─ Open Claude.ai or Cursor
   └─ Paste prompt + spec
   └─ Hit enter

3. WAIT FOR BUILD
   └─ Claude builds: 10–20 minutes
   └─ Gets back: Code + test results

4. RUN TESTS LOCALLY
   └─ Save Claude's code to file
   └─ Run: pytest scenario5_tests.py -v
   └─ Note: Which tests PASS, which FAIL

5. DIAGNOSE & ITERATE
   └─ For each failure:
      • Classify using taxonomy (see below)
      • Apply fix (update spec or tell Claude to fix code)
      • Re-run tests
   └─ Loop until: All V1–V10 PASS
```

## THE 4-PART TAXONOMY (DIAGNOSE BEFORE FIXING)

### When a test fails, ask: "Is the spec clear?"

#### YES, SPEC IS CLEAR
→ **BUILDER MISREAD** (Claude owns fix)

**What to do:**
1. Find exact spec line Claude should have read
2. Show it to Claude
3. Say: "Your code [what it does]. Spec says [quote]. Fix this."

**Example:**
- Spec: "If insurance status ≠ active, escalate"
- Claude's code: Only escalates on INACTIVE (not ERROR, not TIMEOUT)
- Message: "FR3 says escalate if status ≠ active. ERROR and TIMEOUT are not active. Escalate on all non-active statuses."

---

#### NO, SPEC IS UNCLEAR
→ **SPEC AMBIGUITY** (You own fix)

**What to do:**
1. Rewrite the spec to be explicit
2. List all possible interpretations
3. Say which one is correct
4. Send updated section to Claude

**Example:**
- Old spec: "Validate address is valid"
- New spec: "Geocode address in USPS database. If found → valid. If not found → invalid. If timeout → escalate."

---

#### CODE CORRECT, TEST WRONG
→ **TEST PROBLEM** (Test owns fix)

**What to do:**
1. Fix the test logic (not the code)
2. Re-run

**Example:**
- Spec: "Round half up"
- Claude: Implements correctly
- Test: Expects floor behavior
- Fix: Change test expectation to match round-half-up

---

#### SPEC MISSING REQUIREMENT
→ **DESIGN GAP** (Spec owns fix)

**What to do:**
1. Add missing requirement to spec
2. Send updated spec to Claude

**Example:**
- Spec: "Log QUESTIONNAIRE_SENT"
- Missing: What channel? (email, SMS, portal)
- Fix: Update spec to include channel in log
